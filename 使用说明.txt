知源 · 马克思主义理论学习平台
====================================

怎么打开
--------
双击 index.html 即可。不需要安装任何软件，不需要联网，不需要本地服务器。

推荐浏览器：Edge / Chrome / Firefox（近两年的版本都行）。
IE 打不开，别试。

里面有什么
----------
index.html          总入口（六屏应用 / 四篇原文 / 书目总表）
app/index.html      主应用，六个屏；键盘按 1-6 或 ←→ 切换
app/works/          四篇经典原文 + 书目总表，各自独立一页
app/css/ app/js/    样式与脚本，不用管

发给别人
--------
在线版：如果已经发布，直接发网址就行（见下方「在线版」）。

离线版：把整个文件夹压成 zip 发过去，对方解压后双击 index.html。
不要只发 index.html 一个文件——它依赖 app/ 目录，单独发会丢样式。

在线版
------
发布到 GitHub Pages 后，网址形如：

    https://<用户名>.github.io/zhiyuan/

手机、平板、别的电脑都能直接打开，不用传文件。
国内访问 github.io 有时偏慢，属正常现象，多刷一次即可。

关于字体
--------
字体优先用系统自带的宋体 / 黑体，联网时会自动加载更好的思源宋体与楷体。
断网也能正常显示，只是字形朴素一些，不影响阅读。

关于内容（重要）
--------------
1. 学者姓名与机构为真，但页面上的批注文字是「导读要点」，不是伪造的直接引语。
2. 原文页只做关键段落节选——马恩著作中文译文有版权，整章复制属侵权。
3. 书目总表里九本教材没有免费全文，给的是检索路径，不是假链接。
4. 界面所标页码用于检索定位，正式引用请核对纸本。
