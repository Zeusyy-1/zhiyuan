# 知源 · 马克思主义理论学习与研究支持

给武汉大学马克思主义理论专业本科阶段做的一套学习平台。核心不是「多给资料」，而是**把原典、二手文献与名家导读放进同一条证据链**：每条批注都标出处，查不到的明写「待核实」。

## 里面有什么

| 部分 | 内容 |
|---|---|
| 六屏主应用 | 首页 / 学习工作台 / 经典精读 / 成长路线 / 来源核验 / 通用学习面板 |
| 经典原文库 | 4 篇带页边朱批与章节思维导图，附 GB/T 7714 引用块 |
| 书目总表 | 15 本，按「公开可查 / 馆藏检索 / 纸本必读」三级标注 |

入口：`index.html`（总览）→ `app/index.html`（主应用）。

## 技术形态

纯静态，零构建、零依赖、零外部数据请求。相对路径，可放在任意子目录下托管。

- 桌面：1440 固定画布 + `zoom` 等比缩放
- 窄屏：`max-width: 820px` 命中单列重排，不再整体缩小
- 键盘：`1`–`6` 切屏，`←` `→` 翻页

## 内容底线

1. 学者与机构真实，批注写成「导读要点」，不伪造直接引语
2. 页码为界面占位，正式引用须核对纸本
3. 不写「党史三卷」——《中国共产党历史》第三卷未出版
4. 《中国共产党的七十年》止于 1991，此后史事另找出处

## 本地打开

双击 `index.html` 即可。若浏览器限制本地文件读取，可用：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

本仓库根目录即站点根目录，GitHub Pages 选 `main` / `/ (root)` 直接可用。
